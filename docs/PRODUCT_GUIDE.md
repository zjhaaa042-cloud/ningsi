# 凝思 · 产品使用说明（系统架构与流程说明）

对应赛题提交材料「（5）① 产品使用说明文档（系统架构与流程说明）」。
版本：0.1.0；口径：`welch-v1` / `indicator-v1` / `baseline-v1` / `joint-assessment-v1` / `neurofeedback-v1` / `logistic-v1`。

---

## 1. 系统定位与适用范围

凝思面向**便携脑电设备的专注力强化训练与心理状态评估**。它把一次使用拆成"采得可信 → 判得有据 → 练得有效"三段：
先做设备质检与伪迹门控，确保进入指标的是可信窗；再用个体基线把绝对功率变成可比的变化量，
与量表、行为任务一起做联合判断；最后用实时专注度驱动反馈训练，并把训练前后的同口径数据留档。

适用：考前/任务前状态自查与调节、按周进行的专注力训练周期、校园与机构的团体活动、认知负荷与疲劳的观察性研究。
不适用：任何医疗诊断、临床治疗决策、对个人的考核或处罚。

## 2. 系统架构

四层结构，底部由数据安全与合规横条贯通：

```
用户层      学生 / 职场人群 / 个人用户 / 心理教师与辅导员 / 员工关怀负责人 / 研究人员
              │
交互层      设备接入与质检 │ 评估与量表 │ 实时监测 │ 训练主界面 │ 报告与趋势
              │   （app/ui.py 五个页签；CLI 提供同一套能力的脚本入口）
智能层      四级处理链 → Welch 频谱 → 频带特征 → 三指标 → 质量门控 → 联合评估 → 模型与建议
              │   （signal/ · behavior/ · assessment/ · models/）
支撑层      LSL 采集抽象 │ 文件与 JSONL 落盘 │ 口径与版本管理 │ 可复算的证据回填
              │   （acquisition/ · monitoring/history.py · config.py · assessment/report.py）
════════════════════════════════════════════════════════════
横条         数据安全与合规：匿名编号、受限目录、不作医疗诊断、结论只给操作建议
```

| 模块 | 代码路径 | 职责 |
|---|---|---|

| 热力图 | `monitoring/heatmap.py` | 五档着色、缺失色块、SVG 输出 |
| 历史与趋势 | `monitoring/history.py` | 记录追加、可比性过滤、周/月聚合与趋势图 |

## 3. 使用流程（单次会话九步）

```
① 安装与启动 → ② 设备接入与质检 → ③ 量表填写 → ④ 静息基线
   → ⑤ 行为任务（SART / PVT-B） → ⑥ 指标与热力图实时监测
   → ⑦ 联合评估与报告 → ⑧ 神经反馈训练 → ⑨ 趋势复评
```

1. **安装与启动**：`pip install -e .` 后执行 `ningsi ui`（桌面）或 `ningsi demo`（无设备演示）。
2. **设备接入与质检**：连接 LSL 流后自动扫描通道数与采样率；质检页显示有效通道、恒定/贴轨通道与调整建议。
   质检不通过时不进入正式采集。
3. **量表填写**：SAS、SDS 各 20 题，4 级作答；系统按反向题规则计分并给出粗分、标准分与分级。
4. **静息基线**：睁眼静息窗若干（默认 8 窗），逐窗质检；至少 5 个合格窗才建立基线，否则明确拒绝出趋势。
5. **行为任务**：SART 180 试次（20 个 No-Go，8 套序列按被试/会话/Run 确定性轮换）+ PVT-B 3 分钟。
6. **实时监测**：每 2 秒推进一个 4 秒窗，实时显示三指标、波形与频谱、可用窗比例与不可用原因；
   热力图按窗着色，质量不合格窗用独立"缺失"色块，不参与指标与预警计时。
7. **联合评估与报告**：按"证据独立计算 → 质量前置判定 → 一致性检查 → 结论输出 → 边界提示 → 证据回填"生成报告。
8. **神经反馈训练**：初始目标取自当次基线中位数对应的评分；每段记录平均专注度、达标时间占比与波动幅度，
   下一段按表现调整目标（步长 0.05）与保持时长（6–20 秒）；训练前后各采一次静息基线用于同口径对比。
9. **趋势复评**：历史按周/月聚合；设备、采样率或通道数变化时明确标注不可比，不画不可比的曲线。

## 4. 界面说明（桌面端五个页签）

| 页签 | 内容 | 状态含义 |
|---|---|---|
| 状态指标 | 专注度/放松度/认知负荷三条进度条 + 数值 | 0–1 评分，0.5 表示与个体基线持平 |
| 状态热力图 | 逐窗色块（每格 2 秒） | 五档颜色对应 0–1 分档；灰色格=低质量缺失 |
| 神经反馈训练 | 反馈圆（大小/颜色随专注度变化）+ 分段记录 + 下一段目标 | 圆大于目标阈值时为达标状态 |
| 评估报告 | 完整 Markdown 报告 | 含结论、建议与证据回填 |
| 历史趋势 | 专注度周趋势折线 | 仅同一设备配置内的记录才参与 |

## 5. 指标与口径定义

| 指标 | 定义 | 取值范围 | 证据来源 |
|---|---|---|---|
| 专注度 | 相对基线的 log(β/θ) 经逻辑映射 | 0–1 | Welch PSD → 频带功率 → 相对基线 z |
| 放松度 | 相对基线的 log(α/β) 经逻辑映射 | 0–1 | 同上 |
| 认知负荷 | 相对基线的 log(θ/α) 经逻辑映射 | 0–1 | 同上 |
| 采集质量 | 4 秒窗可用比例与不可用原因分布 | 0–100% | 幅度/恒定/跨度/肌电/眼电判定 |
| 行为表现 | SART 正确率、虚报率、漏报率、反应时与变异 | 计数与秒 | 试次级作答记录 |
| 警觉水平 | PVT-B 中位反应时、慢反应率、抢答次数 | 秒与比例 | 试次级作答记录 |
| 量表 | SAS/SDS 粗分与标准分（粗分×1.25） | 20–80 / 25–100 | 题目定义与反向题规则 |

所有指标都保留"原始频带功率 + 基线统计量 + z 值 + 评分"四层数据，任一次评分都可以沿链路回算。

## 6. 质量门控与预警规则

| 规则 | 阈值 | 触发条件 | 解除条件 |
|---|---|---|---|
| 单窗伪迹 | 幅度 >150 µV；恒定通道 std <2 µV；通道跨度 >100 µV；30–45 Hz 相对功率 >0.35；0.5–4 Hz 相对功率 >0.55 | 立即判为不可用窗，记录原因 | —— |
| Run 级质量 | 可用窗比例 <60%，或连续 3 个不可用窗 | 质量不足提示 | 可用窗比例恢复 |
| 低专注预警 | 评分 <0.35 持续 20 秒 | 触发提示"先做 1 分钟放松" | 评分 ≥0.45 持续 10 秒 |
| 高负荷预警 | 评分 ≥0.75 持续 30 秒 | 触发提示"休息并放慢节奏" | 评分 ≤0.65 持续 15 秒 |

预警计时以"连续越界时长"为准，质量不合格窗不参与计时（等于停表），避免因动作伪迹误报。

## 8. 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 提示"未安装 pylsl" | 未安装 LSL 客户端 | `pip install "ningsi[lsl]"`；或先用仿真源演示 |
| 提示"未发现 EEG 流" | 设备未 Start 或不在同一网段 | 在设备端确认已发布 LSL 流并处于同一局域网 |
| 基线无效 | 合格窗少于 5 个 | 重新佩戴并保持安静，重采基线 |
| 报告出现"结果不一致" | 脑电指标与量表/行为方向不一致 | 在安静环境、固定佩戴位置下复测，优先核对伪迹比例 |
| 趋势不显示新记录 | 设备/采样率/通道数与历史不同 | 属可比性保护，界面会标注不可比原因 |
| 报告出现"数据不足" | 缺少量表或行为任务，或质量不达标 | 补齐评估环节后重新生成报告 |

## 9. 边界声明

本产品用于研究、竞赛与自我调节训练，不提供医疗诊断；量表结果与脑电指标只作状态提示。
任何结论不得用于处罚、自动上岗决策或永久能力画像。报告中的每条结论都附证据回填，
如与实际情况不符，应优先检查设备佩戴与采集质量，而不是直接采信结论。
